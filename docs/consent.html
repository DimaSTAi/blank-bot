Согласие на обработку персональных данных

Дата публикации: 08.07.2026

Настоящим я, Пользователь сервиса «Бланк-бот» (далее — «Сервис»), действуя свободно, своей волей и в своём интересе, даю согласие оператору персональных данных — Стаднику Дмитрию Олеговичу, действующему в статусе самозанятого (далее — «Оператор»), на обработку моих персональных данных.

1. Состав персональных данных

1.1. В зависимости от выбранного документа Оператор может обрабатывать следующие персональные данные:

  • фамилия, имя, отчество;
  • дата рождения;
  • паспортные данные (серия, номер, кем и когда выдан, код подразделения);
  • адреса регистрации и/или проживания;
  • контактный телефон и email;
  • идентификатор пользователя Telegram (user_id) и никнейм;
  • иные сведения, необходимые для заполнения конкретного документа.

2. Цели обработки персональных данных

2.1. Обработка персональных данных осуществляется исключительно в следующих целях:

  • генерация PDF-документа по запросу Пользователя;
  • отправка готового документа Пользователю в Telegram;
  • обработка платежей через платёжную систему ЮKassa;
  • связь с Пользователем в случаях, предусмотренных законодательством или настоящим согласием.

3. Способы обработки

3.1. Оператор осуществляет сбор, запись, систематизацию, накопление, хранение, уточнение, извлечение, использование, обезличивание, блокирование, удаление и уничтожение персональных данных.

3.2. Обработка ведётся с использованием средств автоматизации.

4. Срок обработки и хранения

4.1. Персональные данные обрабатываются в течение времени, необходимого для генерации и выдачи документа, но не более 3 (трёх) дней с момента выдачи документа.

4.2. По истечении указанного срока персональные данные и сгенерированные PDF-файлы автоматически удаляются с сервера Оператора.

5. Передача третьим лицам

5.1. Оператор не передаёт персональные данные третьим лицам, за исключением:

  • платёжной системы ЮKassa — только сведения, необходимые для обработки оплаты (ID платежа, сумма, описание);
  • случаев, предусмотренных законодательством Российской Федерации.

6. Права Пользователя

6.1. Пользователь вправе:

  • получать информацию о том, какие данные о нём обрабатываются;
  • требовать уточнения, блокирования или удаления данных;
  • отозвать настоящее согласие, прекратив использование Сервиса.
