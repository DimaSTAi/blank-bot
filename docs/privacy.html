Политика конфиденциальности

Дата публикации: 08.07.2026

1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки персональных данных Пользователей сервиса «Бланк-бот» (далее — «Сервис»).

1.2. Оператор персональных данных: Стадник Дмитрий Олегович, действующий в статусе самозанятого (далее — «Оператор»).

1.3. Используя Сервис, Пользователь выражает согласие с настоящей Политикой.

2. Какие данные собираются

2.1. Для генерации документов Сервис может запрашивать следующие данные:

  • ФИО;
  • паспортные данные;
  • адреса регистрации и проживания;
  • реквизиты договора, товара или транспортного средства;
  • идентификатор Telegram (user_id) и никнейм;
  • иная информация, необходимая для заполнения конкретного документа.

3. Цели обработки данных

3.1. Данные обрабатываются исключительно для:

  • генерации PDF-документа по запросу Пользователя;
  • отправки готового документа Пользователю в Telegram;
  • обработки платежей через платёжную систему ЮKassa.

4. Хранение и удаление

4.1. Персональные данные, введённые Пользователем, хранятся только на сервере Сервиса в течение времени, необходимого для генерации документа.

4.2. Автоматическое удаление всех персональных данных и сгенерированных PDF-файлов происходит через 3 (три) дня после выдачи документа.

4.3. Готовый PDF-документ остаётся доступен Пользователю в переписке Telegram после отправки.

5. Передача третьим лицам

5.1. Оператор не передаёт персональные данные Пользователей третьим лицам, за исключением:

  • платёжной системы ЮKassa для обработки оплаты (только ID платежа, сумма и описание);
  • случаев, предусмотренных законодательством Российской Федерации.

6. Безопасность

6.1. Оператор принимает разумные меры для защиты данных от несанкционированного доступа, изменения или удаления.

6.2. Данные передаются через защищённые соединения Telegram и HTTPS.

7. Права Пользователя

7.1. Пользователь вправе:

  • узнать, какие данные о нём обрабатываются;
  • требовать удаления данных до истечения срока автоматического удаления;
  • отозвать согласие на обработку, прекратив использование Сервиса.
